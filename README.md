# NewAPI 中转站一键签到 · Chrome / Edge 扩展

一个运行在 Google Chrome 和 Microsoft Edge 中的 Manifest V3 侧边栏扩展，用于管理多个 NewAPI / 兼容站点，并手动或定时执行签到、领取额度。界面、代码与设计均为本项目原创，不绑定任何具体站点运营方。

> ⚠️ 本项目为**非官方工具**，仅供学习与个人使用。使用前请阅读下方[使用须知与免责声明](#使用须知与免责声明)。

版本更新内容请查看 [CHANGELOG.md](CHANGELOG.md)。
版本更新可以提前将插件保存的网站进行导出，然后更新完成后再进行导入。

## 功能

- 在 Chrome / Edge 侧边栏或新标签页管理多个站点；
- 支持「访问令牌」「Agent Router（GitHub 重登录签到）」与「登录 Cookie」鉴权方式；
- 单个平台签到和一键批量签到；
- 支持需要 Cloudflare Turnstile 人机验证的签到站点；
- 支持自定义每日签到时间、浏览器启动补检和签到确认通知；
- 可选择「自动允许一键签到」，到达设定时间后无需再次确认；
- 查看本月签到、额度和 Token 统计；
- 「模型」面板按站点真实流量查看各模型可用性、成功率、平均延迟与平均 TPS（只读，不调用模型、不消耗额度）；
- 卡片上的站点网址可直接点击，在浏览器新标签页打开；
- 支持明 / 暗双主题切换，主题偏好本地记忆；
- 配置仅保存到浏览器 `chrome.storage.local`，令牌不出浏览器；
- 支持导入 / 导出本地 JSON 配置。

## 安装

Chrome 和 Edge 使用同一份扩展源码，无需下载不同版本。

### Google Chrome

1. 下载或克隆本仓库。
2. 打开 Chrome 的 `chrome://extensions/`。
3. 开启右上角的「开发者模式」。
4. 点击「加载已解压的扩展程序」，选择本仓库根目录（其中应包含 `manifest.json`）。
5. 将扩展固定到工具栏，点击图标打开侧边栏；也可点击界面中的「展开」进入宽屏管理页。

建议使用 Chrome 116 或更高版本。较旧版本不支持侧边栏时，点击扩展图标会自动打开宽屏管理页。

### Microsoft Edge

1. 下载或克隆本仓库。
2. 打开 Edge 的 `edge://extensions/`。
3. 开启「开发人员模式」。
4. 点击「加载解压缩的扩展」，选择本仓库根目录（其中应包含 `manifest.json`）。
5. 将扩展固定到工具栏，点击图标打开侧边栏；或在管理页点「展开」进入宽屏视图。

建议使用 Edge 116 或更高版本。

## 使用

### 访问令牌模式

添加平台时填写站点首页地址、站点「个人设置」中生成的**系统访问令牌**，以及某些兼容站点要求的 `New-Api-User` 用户 ID。

> 注意：必须是「个人设置」里的**系统访问令牌**，不是「令牌管理」里的 API 令牌（`sk-` 开头）。签到接口只认前者，填错会报令牌无效或权限不足。

令牌只在浏览器本地保存，用于直接请求你配置的站点。**请不要把包含令牌的导出文件提交到 GitHub 或发送给他人。**

### Agent Router GitHub 重登录签到模式

`agentrouter.org` 可选择专用的「Agent Router（GitHub 重登录签到）」模式。填写数字用户 ID，并确保浏览器已登录对应账号。扩展会先校验网站本地保存的当前用户 ID，再调用网站原生退出接口并启动 GitHub OAuth。

Agent Router 当前版本在登录接口和 OAuth 回调响应的 `checked_in` 字段中返回签到结果，因此签到依赖浏览器 Cookie 会话，不需要系统访问令牌。若 GitHub 要求验证码、授权或输入凭据，请在临时页面中手动完成。

### 登录 Cookie 模式

部分站点不允许使用系统访问令牌签到，只允许已登录浏览器会话调用接口：

1. 先在当前使用的 Chrome 或 Edge 中登录目标站点；
2. 添加平台时选择「登录 Cookie」；
3. 扩展会在该站点自己的标签页中发起同源请求，让浏览器自动携带登录会话。

扩展不会读取、拼接或上传 Cookie 字符串。站点的登录状态仍由浏览器和站点自身管理。

#### Agent Router 特殊处理

`agentrouter.org` 在用户重新登录时完成签到。每次签到（包括批量和定时签到）会调用 `/api/user/logout`，然后打开该站点登录页并开始 GitHub OAuth；插件不会代填密码或验证码。

扩展会使用 Agent Router 自己的 `/api/oauth/state` 和 GitHub Client ID，在临时标签页中发起 GitHub OAuth。OAuth 返回后，网站会调用 `/api/oauth/github`，把包含 `checked_in` 的登录结果写入本地用户状态；扩展确认该状态后关闭临时标签页。若 GitHub 要求输入账号、验证码或确认授权，页面会保留供你手动完成。

如果站点返回登录页或安全验证页面而不是 JSON，扩展会将其识别为登录会话失效/安全校验，并保留登录页供你处理，不再显示笼统的“无法解析的数据”。

### Turnstile 验证签到

部分 NewAPI 站点会在签到接口上启用 Cloudflare Turnstile。扩展检测到「Turnstile token 为空」后，会自动打开或复用目标站点标签页，并在站点页面内显示官方人机验证控件。

用户完成验证后，扩展会自动携带一次性 Turnstile token 提交签到。若标签页由扩展临时创建，会在验证和签到请求完成后自动关闭；用户原本已经打开的站点标签页不会被关闭。

Turnstile 由目标站点和 Cloudflare 提供，扩展不会绕过、伪造或保存验证 token。

### 每日定时签到

开启「定时自动签到」后，可以设置每天的签到时间，例如 08:01：

1. 浏览器在设定时间运行时，扩展会检查当天是否已经执行过一键签到；
2. 如果浏览器当时没有运行，会在当天下一次启动浏览器时补检；
3. 扩展先查询各站点当天的签到状态，只处理尚未签到的平台；
4. 默认通过浏览器通知询问是否允许一键签到，可以选择「允许签到」或「跳过今天」；
5. 开启「自动允许一键签到」后，到达时间会直接执行，无需再次确认。

需要 Turnstile 的站点仍可能打开验证页面等待用户完成验证，无法保证完全无人值守执行。

### 模型可用性面板

在宽屏管理页（点击侧边栏的「展开」进入）中，每张平台卡片会多出一个「模型」按钮，点击后打开模型可用性面板：

1. 面板顶部可切换统计窗口（最近 24 / 72 / 168 小时）、搜索模型名、勾选「仅显示有流量的模型」；
2. 概览表格列出站点支持的全部模型，并显示成功率、平均延迟、平均 TPS 和健康状态；
3. 点击任意一行展开该模型的明细与走势迷你图，再次点击同一行即收起。

数据来源分两种：

- **站点性能指标**（较新 NewAPI 内核提供的 `GET /api/perf-metrics`）：由站点自身按全站真实流量统计，覆盖面最完整；
- **我的调用记录**（站点不支持上面的接口时自动降级）：改用 `GET /api/log/self` 聚合你自己的调用日志，最多采样最近 600 条记录，因此只反映你个人的调用情况。

整个过程全程只读：不会发起任何模型请求，不消耗额度，也不会触发签到。三种鉴权模式（访问令牌 / 登录 Cookie / Agent Router）都可使用，Cookie 与 Agent Router 模式会在站点自己的标签页内发起同源请求。

> 侧边栏窄屏视图不显示「模型」按钮，表格在宽屏下才有足够空间。

### 明 / 暗主题

顶部 / 侧边栏顶部的 ☾ 按钮可切换深色与浅色界面。首次访问跟随系统偏好，之后的选择保存在本地。删除浏览器数据后需重新选择。

## 权限和数据处理

| 权限 | 用途 |
| --- | --- |
| `storage` | 保存平台配置和自动签到设置 |
| `alarms` | 检查每日签到时间并在浏览器启动后补检 |
| `notifications` | 显示签到确认和执行结果通知 |
| `tabs` | 打开管理页、复用或创建目标站点验证标签页 |
| `scripting` | 在目标站点标签页内发起同源请求及显示 Turnstile 验证 |
| `sidePanel` | 承载 Chrome / Edge 侧边栏界面 |
| `<all_urls>` | 访问用户自行配置的站点接口 |

扩展没有内置的中转服务器、统计服务或远程数据上传逻辑。请求只发往用户配置的目标站点。

## 兼容性与限制

- 主要兼容 NewAPI 的 `/api/user/checkin` 接口及部分兼容实现；
- 不同站点可能修改接口、鉴权方式或签到规则；
- Turnstile 验证需要在目标站点页面内完成，站点要求交互时无法完全静默签到；
- 浏览器完全退出时定时任务不会运行，但会在当天再次启动浏览器后补检；
- 模型面板的全站性能指标需要站点使用较新的 NewAPI 内核（提供 `/api/perf-metrics`）；老内核会自动降级为个人调用日志统计；
- 每分钟请求数（RPM）与站点限流配额上游接口未对普通用户开放，因此面板不展示该项；
- 目标站点可能禁止自动化请求，使用前请阅读并遵守其服务条款。
